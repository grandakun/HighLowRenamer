# 高低模批量命名工具 (High/Low Poly Batch Renamer) v5.7

这是一个专为 Autodesk Maya 设计的 Python 工具，旨在通过分析模型的空间位置和面数，自动化完成高低模（High-poly / Low-poly）的匹配、重命名以及分组归类工作，极大提升烘焙前期的资产整理效率。

## ✨ 核心功能

* **智能空间匹配**：基于模型的边界盒中心点（Bounding Box Center）和面数（Face Count）自动匹配同一位置的高低模。
* **安全清理机制**：在预览或执行前，自动静默清理多余的孤立 Intermediate Shape。内置白名单，带蒙皮、BlendShape 等变形器的资产会被严格跳过，确保有效数据安全。
* **一键安全撤销**：所有的清理和重命名动作被合并进同一个 Undo Chunk，执行完毕后可通过一次 `Ctrl + Z` 完美撤销。
* **极佳的稳定性**：
* 底层采用长路径（Long Path）进行判断和重命名，彻底避免 Maya 中常见的短名冲突导致的误操作。
* 对无渲染 Shape、Reference 锁定节点等极端场景做了空值保护，避免脚本崩溃。


* **大纲视图整理**：支持将完成配对的资产分别放入对应的高低模组中，并提供“名称排序”功能，按自然数字顺序重排 Outliner 层级。

## 🚀 安装与运行

本工具兼容 Maya 环境下的 PySide2 与 PySide6。

1. 将 `HighLowRenamer.py` 放入您的 Maya 脚本目录（例如 `Documents/maya/scripts`）。
2. 在 Maya 的 Python 脚本编辑器中运行以下代码即可呼出 UI：

```python
import HighLowRenamer
HighLowRenamer.show()

```

## ⚙️ 参数与设置说明

每次打开工具时，面板参数均会自动恢复为安全默认值。

### 资产设置 (Asset Settings)

| 参数名称 | 描述 | 默认值 |
| --- | --- | --- |
| **资产名** | 重命名的基础前缀 (Asset Name) | `polymesh` |
| **起始编号** | 序列号的起始数字 | `1` |
| **编号位数** | 序列号补零的位数 (例如 2 代表 01, 02) | `2` |
| **高/低模后缀** | 附加在序号后的名称标识 | `high` / `low` |
| **高/低模组名** | 归类组的名称 (若存在同名会自动加数字后缀) | `high` / `low` |

### 配对参数 (Pairing Parameters)

| 参数名称 | 描述 | 默认值 |
| --- | --- | --- |
| **精度 (Precision)** | 空间坐标的量化精度。值越小要求两模型中心点重叠度越高。 | `0.50` |
| **容差 (Tolerance)** | 当模型未能完美重合时，允许的最大二次查找空间距离。 | `1.00` |
| **阈值 (Threshold)** | 判定高低模的面数倍数界限。例如设为 1.5，则面数大于另一方 1.5 倍的即为高模。 | `1.50` |

## 🛠️ 界面操作指南

* **刷新**：读取当前场景中选中的 Mesh 并显示有效数量。
* **预览**：在文本日志中输出预期的匹配结果（高模<=>低模），并列出未能成功匹配的孤立模型，**不会**对节点进行实际重命名。
* **执行**：实际运行重命名逻辑，并将模型移动到对应的组内。
* **选中高模 / 选中低模 / 全选**：快速一键选中指定组别下的所有有效 Mesh 节点。
* **名称排序**：针对生成的高低模组，将其内部子节点按后缀序号进行自然排序（Natural Sort），使 Outliner 保持整洁。
